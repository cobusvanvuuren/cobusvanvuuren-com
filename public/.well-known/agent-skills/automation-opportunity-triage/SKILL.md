# Automation Opportunity Triage

This is the core method behind Cobus van Vuuren's Business Automation Assessment
(https://cobusvanvuuren.com/audit/). It is diagnostic-led, not tool-first: map the
process before recommending anything.

## The method

1. **Map every process where time is currently spent**, not just the ones that already
   feel painful. Blind spots are common -- the process a principal has done manually for
   years often no longer registers as "a process."
2. **Rank by ROI, not by ease of implementation.** Score each candidate on:
   - Hours currently spent per week/month
   - Hourly value of the person doing it (for billable-hours businesses, this is direct
     revenue, not just "admin time")
   - Error/rework cost when done manually
   - One-off setup cost and effort vs. ongoing cost
3. **Sequence, don't parallelize.** Fix the highest-ROI process first, fully, before
   moving to the next. Partial automation across five processes usually delivers less
   than full automation of the top one.
4. **Specify tooling only after ranking**, scoped to the business's actual size, existing
   stack, and team's technical comfort -- not a generic best-practice list.

## When this applies

Any business where time is billed or where manual admin directly delays revenue --
professional services (accounting, legal, financial advisory) are the clearest case,
since every hour on manual process is an hour not billed.

## What this is not

Not a generic "digital transformation" framework. It does not assume automation is
always the answer -- some processes rank low enough that leaving them manual is the
correct call.
